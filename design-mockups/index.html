Claude GUI · UI/UX 方案

同一套界面(侧栏 + 对话 + 输入框)的四个设计方向,内容一致便于对比。点开任一卡片查看全屏效果。玻璃两版只换折射技术,其余完全一致。
方案 01
液态玻璃 · CSS 仿真
backdrop-filter + 多层高光/边缘高光模拟玻璃质感,深色氛围背景透出折射感。无真实位移,但全平台一致。
Tauri/WebKit ✓ Chrome ✓
方案 02
液态玻璃 · 真折射
复刻 liquid-glass-react:SVG feDisplacementMap 真实弯折背景边缘。效果最惊艳,但仅 Chromium 生效,Tauri/Safari 退化为毛玻璃。
Chrome ✓ Tauri/WebKit ✗ 退化
方案 03
编辑 · 暖陶
亮色暖纸 + Fraunces 衬线 + IBM Plex Mono,Claude 陶土色点缀。安静、有书卷气,长时间阅读舒适。
全平台 ✓
方案 04
终端 · 极简开发
深色 + JetBrains Mono 等宽 + 锐利栅格 + 荧光高亮。高密度、工具感强,贴合开发者直觉。
全平台 ✓
